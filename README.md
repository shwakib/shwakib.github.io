# Sifat Hasan Wakib · Portfolio

Personal portfolio of **Sifat Hasan Wakib**, a network engineer based in Windsor, Ontario, with ISP network operations experience and a peer-reviewed ACM paper.

**Live site: [sifatwakib.com](https://sifatwakib.com)**

## What's on the site

- **Experience:** InfoLink Limited (NOC), Sutherland Global Services, and Loblaws, each with a details popup
- **Education:** Master of Applied Computing (University of Windsor), B.Sc. in CSE (AIUB), HSC and SSC
- **Research:** [A Traffic Flow Steering Algorithm for Hybrid Terrestrial-Satellite Backhaul Network](https://doi.org/10.1145/3542954.3543040) (ACM ICCA '22) and its [code](https://github.com/shwakib/Traffic-Flow-Steering-Algorithm)
- **Skills:** a logo grid of networking, hardware, monitoring, cloud/DevOps and development tools
- **Projects:** UniInfoHub and AnyoneIn
- **Contact:** a contact form and email

## Built with

A single, dependency-free HTML file: plain HTML, CSS and vanilla JavaScript, no build step. Skill logos load from [Simple Icons](https://simpleicons.org/) on the jsDelivr CDN, and the contact form uses [FormSubmit](https://formsubmit.co/).

Hosted on GitHub Pages with a custom domain and DNS through Cloudflare.

## Run it locally

```bash
git clone https://github.com/shwakib/shwakib.github.io.git
cd shwakib.github.io
python3 -m http.server 8000
```

Then open http://localhost:8000.
